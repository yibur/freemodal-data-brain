# 已核验信源填写模板

> **本文件是填写说明，不是额度数据。** 严禁把本模板里的示例数值当成真实额度发布，也严禁用示例数据自证能力。

## 一、往哪里填

编辑 `sources/offers.json` 的 `verified_offers` 数组，每核验通过一家平台，追加一条对象。初始为空数组 `[]`，表示**尚无已核验记录**——这是诚实状态，不是待补的占位符。

## 二、单条记录的字段

```json
{
  "provider": "平台名称",
  "modality": "image",
  "quota": { "unit": "count", "amount": 50, "period": "once" },
  "watermark": "none",
  "commercial_rights": "allowed",
  "queue_speed": "instant",
  "resolution": "2k",
  "note": "可选备注",
  "_verified_at": "2026-11-13T05:00:00+00:00",
  "_official_homepage_confirmed": true,
  "_anchor_checked_at": "2026-11-13T05:00:00+00:00"
}
```

| 字段 | 必填 | 取值 | 说明 |
| :--- | :--- | :--- | :--- |
| `provider` | 是 | 非空字符串 | 平台名，不得含第三方品牌词、不得含链接 |
| `modality` | 是 | `image` / `video` | 生图或生视频 |
| `quota.unit` | 是 | `count` / `second` / `credit` | 按次 / 按秒 / 按积分 |
| `quota.amount` | 是 | ≥ 0 的数字 | 原始额度数值，不折算、不夸大 |
| `quota.period` | 否（建议填） | `once` / `daily` / `per_style_daily` / `monthly` / `unknown` | 额度周期：一次性 / 每日 / 每日每风格 / 每月。缺失按 `unknown` 处理，技能端不会把它算进「今日可用」；一次性额度也不要写成 `daily` |
| `watermark` | 是 | `none` / `visible` / `conditional` | 水印情况；不确定填 `conditional` |
| `commercial_rights` | 是 | `allowed` / `restricted` / `unknown` | 商用版权；**不确定就填 `unknown`，不许猜** |
| `queue_speed` | 是 | `instant` / `fast` / `normal` / `slow` | 排队速度 |
| `resolution` | 是 | `1k` / `2k` / `4k` / `720p` / `1080p` / `variable` | 分辨率 |
| `note` | 否 | 字符串 | 备注，**不得含任何链接或引流信息** |
| 下划线开头字段 | 否 | 任意 | 私有核验元数据，**不会进入公开发布的 JSON** |

## 三、核验三步（对应原方案的「三层核验 + 原文锚点」）

1. **官方首页确认**：从平台官方首页进入活动/定价页，确认额度页确属该平台官方域名；不接受二手转载、聚合站截图、社群转述。
2. **原文锚点抄录**：把额度数值、水印、商用权、排队、分辨率五项从原文逐字核对；任一项原文没写，对应枚举填 `unknown` / `conditional`，**不补值、不猜值**。
3. **记录核验时间**：`_verified_at` 写成带 `+00:00` 时区的 UTC 时间。**超过 7 天的记录会被构建脚本自动剔除**，强制你定期复核。

## 四、构建脚本会自动拦截什么

- 缺四字段、枚举非法、额度为负、单位非法、`provider` 非字符串 → **整份清单中止发布**，不输出半截数据。
- 公开产物里出现外链、二维码相关词、第三方品牌词、永久/无限/收益承诺 → 中止发布。
- 任何 `_` 开头字段 → 自动剥离，不泄漏到公开 JSON。
- 核验时间超 7 天或晚于当前时间 → 该条剔除并在日志列出原因。

## 五、合规红线

- 不批量注册、不绕过限流、不伪造身份、不使用他人额度。
- 不使用原开源项目名称与 Logo，品牌统一 **FreeModal**。
- 不承诺「永久免费 / 无限额度 / 保证薅到 / 稳定收益」。
- 抓取第三方页面前自行确认该站点的服务条款与 robots 约束；本骨架**不内置任何爬虫**，只消费你人工核验后录入的清单。
- 所有额度以官方最新公告为准，本数据不构成投资、财务或收益建议。
