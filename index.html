FreeModal 数据脑

人工核验的公开免费额度清单，编译成一份静态 JSON。

当前刷新方式：由 push 和手动 dispatch 触发，定时触发未生效。 工作流里的 schedule 配置仍保留，但它当前不工作。两次触发之间 generated_at 可能长时间不更新；它只在实际 push 或手动 dispatch 后改变。

这个仓库是什么

这里是 FreeModal 的「数据脑」：只收录经官方页面人工核验的公开免费额度信息，经构建脚本清洗后产出一份静态 offers.json，由 GitHub Pages 托管，供技能端匿名只读拉取。

仓库本身是一个静态数据源，不提供登录、不收集用户信息、不代理任何生成请求。额度与政策随时可能调整，一律以各平台官方最新公告为准。

数据怎么用

直接 GET 下面这个地址即可，无需鉴权、无需 API Key：

https://yibur.github.io/freemodal-data-brain/offers.json

顶层字段：

  • schema_version：数据结构版本，当前为 1.0。
  • generated_at：本次产物的生成时间（UTC，ISO 8601）。
  • offers：条目数组。每条含 provider（平台）、modality（模态）、quota（amount / unit / period）、status（核验状态），以及 watermark、commercial_rights、queue_speed、resolution 四个防坑字段和一段 note 说明。
  • source_note：口径与免责说明。

字段语义与降级约定见仓库文档，不在本页重复。
