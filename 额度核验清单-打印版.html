四项防坑字段怎么看

字段取值判定口径
watermarknone / visible / conditional原文写无水印→none；写带水印→visible；只字未提→conditional 并在 note 注明非实测。不许自己下载一张图去猜
commercial_rightsallowed / restricted / unknown定价页或服务条款明确允许→allowed；personal use only / no commercial use→restricted；找不到或措辞模糊→unknown
queue_speedinstant / fast / normal / slow按原文的 priority / standard / no parallel 映射；没提→normal + note 注明「中性占位，非实测」
resolution1k / 2k / 4k / 720p / 1080p / variable单一上限→对应档；多档可选不固定→variable；没写→variable + note 注明

周期口径最易错：一次性别写成 daily（等于放大 30 倍）；Recraft 是 per_style_daily（每风格每天），不是全天总量；原文没说周期填 unknown，不要默认 daily。
